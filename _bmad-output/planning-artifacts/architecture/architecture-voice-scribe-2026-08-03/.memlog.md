- (decision) Use a ports-and-adapters transcript pipeline composed by the VS Code extension entrypoint.
- (decision) TranscriptSession is the sole lifecycle owner; projection and storage consume typed segment-state events rather than provider callbacks.
- (decision) Cleanup concurrency is bounded and results pass an ordered publication barrier keyed by stable segment identity.
- (decision) Raw transcript is immutable provenance; cleaned text is a derived revision and never replaces the stored source.
- (decision) Incognito is enforced at the storage boundary and disables all extension-owned durable writes.
- (assumption) Use the existing TypeScript and Node stack; verify any new SDK version immediately before implementation.
- (question) Cleanup authentication, local-store encryption, retention defaults, and Task Spec schema remain deferred product decisions.
- (decision) A Transcript Session reducer is the only semantic state writer; schedulers and barriers own operational indexes and submit typed outcomes.
- (decision) Transcript Session assigns monotonic segmentSequence at stabilization, and that sequence is the sole publication-order key.
- (decision) Incognito evaluates a registry of every durable capability with deny-dominant policy; visible active output is the only named persistence-like exception.
- (decision) Post-publication retry advances representation version in place and never rewinds the initial Ordered Publication Barrier.
- (decision) Canonical events emit after reducer commit with session event sequence and entity version; consumers are idempotent.
- (decision) Extension-scoped clients and factories outlive sessions; session-scoped handles alone participate in normal stop disposal.
- (decision) Cleanup targets one stable segment and Task Spec or terminal persistence consumes one frozen final session snapshot.
- (event) Adversarial architecture review findings incorporated into the binding spine.
- (constraint) Bundled ws 8.19.0 has a known high-severity advisory and must be locked to 8.21.0 or newer before feature implementation.
- (decision) Preserve shipped behavior but require a supported and audited dependency tuple; runnable local checks alone do not establish acceptance.
- (decision) The VS Code engine floor, VS Code API types, Node types, and extension-host test matrix must describe one proven minimum host.
- (decision) ffmpeg is an unbundled capability contract with platform probes and a support matrix rather than an assumed executable.
- (event) Technology reality review incorporated as architecture gates and prerequisite stories; dependency migration remains outside this documentation change.
